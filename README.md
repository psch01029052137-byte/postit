# Post-it Todo List (구글 시트 연동 포스트잇 웹 애플리케이션)

사용자가 입력한 메모를 감성적인 포스트잇 형태로 출력하고, 드래그 앤 드롭 정렬 및 구글 스프레드시트와의 실시간 CRUD 동기화를 지원하는 반응형 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **중앙 입력 폼 및 포스트잇 스타일 렌더링**
   - 메모 내용 입력 및 범주(할 일, 아이디어, 기타) 선택
   - 4열 그리드 레이아웃: 데스크톱 화면에서 한 행에 최대 4개의 메모 배치 (태블릿 2~3개, 모바일 1개 반응형 전환)
   - 4가지 파스텔 무작위 색상 자동 적용 (노란색, 분홍색, 초록색, 파랑색)
   - 부착 애니메이션(`stickOn` 키프레임)으로 메모가 착! 하고 달라붙는 효과
   - 손글씨 감성의 폰트 및 압정/테이프 디테일 스타일링
   - 좌측 하단에 **연월일 시간 요일**을 작은 글씨로 흐릿하게 표시

2. **라이트 모드 & 다크 모드**
   - 기본값: 라이트 모드 (부드러운 데스크 느낌의 배경)
   - 원클릭 전환 가능한 다크 모드 지원 (눈부심 방지 및 로컬스토리지 상태 보존)

3. **카테고리 필터링 드롭다운**
   - 카테고리(`전체`, `할 일`, `아이디어`, `기타`)별 실시간 메모 필터링

4. **드래그 앤 드롭 이동 (SortableJS)**
   - PC 마우스 드래그 및 모바일 터치 스와이프를 모두 지원하는 정렬 기능
   - 카드 순서 변경 시 구글 시트의 `order` 값도 함께 업데이트

5. **메모 카드 제어 버튼**
   - **체크(완료) 버튼**: 클릭 시 완료 표시(취소선 및 채도 조절), 구글 시트 `state` 열에 완료/진행중 기록
   - **편집(수정) 버튼**: 모달 창을 통해 내용 및 카테고리 즉시 수정 후 시트 반영
   - **삭제 버튼**: 클릭 시 메모 즉시 삭제 및 시트 행 자동 삭제

6. **구글 스프레드시트 CRUD 연동 사양**
   - **A열 (`timestamp`)**: 시트 기록 날짜 및 시간 (날짜 시간 타입)
   - **B열 (`datetime`)**: 메모 생성 날짜 및 시간 (날짜 시간 타입)
   - **C열 (`category`)**: 메모 범주 (문자 타입)
   - **D열 (`content`)**: 메모 내용 (문자 타입)
   - **E열 (`color`)**: 메모 색상 (숫자 타입 0: 노랑, 1: 분홍, 2: 초록, 3: 파랑)
   - **F열 (`state`)**: 상태 (체크/완료 또는 진행중, 문자 타입)
   - **G열 (`order`)**: 메모 순서 (숫자 타입)

7. **타이틀 및 푸터**
   - 메인 타이틀: `<title>Post-it Todo List</title>`
   - 푸터: `Copyright INU Post-it Todo List by OOO`

## 🚀 구글 시트 연동 방법 (Google Apps Script 배포)

1. [Google 스프레드시트](https://sheets.new)를 새로 생성합니다.
2. 상단 메뉴에서 **확장 프로그램** > **Apps Script**를 클릭합니다.
3. 프로젝트 내의 `GoogleAppsScript.js` 파일 내용을 전체 복사하여 스크립트 에디터에 붙여넣고 저장(Ctrl + S)합니다.
4. 우측 상단의 **배포** > **새 배포**를 클릭합니다.
5. 설정(톱니바퀴 아이콘)에서 **웹 앱(Web App)**을 선택합니다.
   - **설명**: `Post-it Backend API`
   - **다음 사용자로 실행**: `나 (My account)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** 로 지정
6. **배포** 버튼을 누르고 권한 검토를 진행한 후 부여되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. [index.html](file:///c:/Users/psch0/Desktop/postit/index.html)을 브라우저로 열고, 우측 상단 **[시트 연동]** 버튼을 클릭하여 복사한 웹 앱 URL을 붙여넣고 **저장**합니다.
   *(※ URL을 등록하지 않아도 로컬 스토리지 모드로 모든 기능을 즉시 테스트하실 수 있습니다.)*
